# Ritika Sonaavane – Portfolio

Personal portfolio site. One file (`index.html`) holds all the content, styling and animations.

## Publish on GitHub Pages
1. Create a new public repository named `<your-github-username>.github.io` (or any name).
2. Upload everything in this folder (`index.html`, `assets/`, `README.md`) to the repository root.
3. Go to **Settings → Pages**, set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`, and save.
4. Your site goes live at `https://<your-github-username>.github.io/` within a minute or two.

## Editing
Open `index.html` in any editor (VS Code, or directly on GitHub with the pencil icon).
The comment at the very top lists what to search for to change each section.

- Résumé download: replace `assets/Ritika_Sonaavane_Resume.pdf` with a newer PDF (keep the same name).
- Colours: change the values under `:root` at the top of the `<style>` block.
